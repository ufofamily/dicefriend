# diceFriend — Compact mono / Performance update

- Верхняя плашка: название пресета, короткая категория и компактный кубик 44×44. Выбор случайного пресета остаётся в текущей категории.
- Убраны декоративные лозунги, неподвижные экранные текстуры, blur и тяжёлые тени. Сохранились страницы параметров и четыре вкладки управления пресетом.
- Фейдеры больше не вызывают перестроение списка вкладок и MIDI-панелей при каждом изменении; значения синтезатора передаются сразу.
- UI-анимация осциллограммы ограничена до 20 Гц при работе, замедлена в покое и отключается на скрытой странице. Основные данные студии обновляются 20 Гц при работе, реже в покое.
- Пресеты, DSP, MIDI, пользовательский JSON и workflow GitHub Pages не изменены.

Для обновления GitHub Pages достаточно заменить `index.html`, `src/style.css`, `src/main.js`, `src/studio.js` и запустить workflow.

ВНИМАНИЕ: статические/Node тесты не заменяют проверку производительности на конкретном устройстве.
