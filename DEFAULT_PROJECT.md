# Стартовый сет diceFriend

Встроенный проект: `src/default-atmoslam-project.json` (полная копия загруженного `dicefriend-studio (11).json`).

- 8 синтезаторных вкладок; BPM 220.
- Активная вкладка: Slambient / Mutating Root.
- Исходное состояние **не запускает звук автоматически**.
- Пользовательские сохранения в localStorage (`dicefriend-generative-project` и `dicefriend-generative-synth`) имеют приоритет над заводским состоянием.
- Чтобы применить новую заводскую конфигурацию в уже использовавшемся браузере: раздел проекта → **«Вернуть исходный сет ATMOSLAM»**. Перед этим экспортируйте свой текущий проект, если хотите его сохранить.

Для следующего обновления заводского сета: экспортируйте проект из приложения и замените им `src/default-atmoslam-project.json`, после чего загрузите изменения в репозиторий GitHub и дождитесь успешной сборки GitHub Actions. При необходимости обновите ожидания в `tests/tabpages-default.mjs`.

Это полный сет, а не один синтезаторный пресет; отдельные пресеты остаются в банке без изменений.
