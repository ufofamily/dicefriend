# ATMOSLAM — вкладки и фейдеры

Изменения UI: три реальные подстраницы **ЗВУК**, **ДЕТАЛИ**, **ГЕНЕРАЦИЯ** на каждой активной вкладке синтезатора. Каждая содержит 6 горизонтальных фейдеров с реальными параметрами DSP или Generator/Filter. Всего на пресет доступны 18 параметров (12 DSP + 6 generator/filter), как и раньше.

- Переключайте страницы кликом по заголовкам или клавишами Left/Right, Home/End при фокусе на заголовке.
- Фейдеры поддерживают мышь, касание, стрелки клавиатуры, колесо и двойной клик (нормализованное значение 50%). Q W E R T Y уменьшают, A S D F G H увеличивают фейдеры активной страницы.
- Крупный кубик пресета остаётся на основной аппаратной панели и заменяет текущий пресет пресетом из выбранной группы.
- Файл `src/default-atmoslam-project.json` — точная копия приложенного пользователем `dicefriend-studio (10).json`: 7 вкладок, 186 BPM, исходные уровни и параметры, sample mute и сохранённые настройки MIDI.
- При первом открытии (при отсутствии сохранённого проекта) загружается этот JSON. Существующие сохранения в localStorage имеют приоритет. Чтобы вернуть фабричное состояние вручную, используйте **Проект → ↺ Вернуть исходный сет ATMOSLAM** с подтверждением.
- Исходный JSON не содержит аудиофайлов или MIDI-файла; загрузить их при необходимости нужно вручную. Автоматически включать звук браузер не будет.
- Для GitHub Pages: публикуйте `dist` через существующий GitHub Actions `.github/workflows/deploy.yml`, Source = GitHub Actions. Файлы исходников нужно загрузить с сохранением папок.
