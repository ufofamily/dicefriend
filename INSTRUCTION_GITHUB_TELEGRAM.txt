diceFriend — готовый сайт для GitHub Pages (без Node.js)

ЭТО СОДЕРЖИМОЕ ПАПКИ САЙТА. Для начала именно этот вариант проще.

1. Создайте публичный репозиторий dicefriend на https://github.com/new .
2. РАСПАКУЙТЕ ZIP на компьютер. На GitHub нужно загружать сами файлы
   index.html, telegram-init.js, папку assets и .nojekyll, НЕ ZIP.
3. В репозитории: Add file → Upload files → перетащите содержимое
   распакованного архива → Commit changes.
4. Settings → Pages → Source: Deploy from a branch → main → /(root) → Save.
5. После публикации получите адрес вида
   https://USERNAME.github.io/dicefriend/
   (USERNAME = ваш логин; название репозитория вместо dicefriend).
6. Проверьте в браузере START AUDIO, DICE и звуковые движки.
7. Откройте https://t.me/BotFather → /newbot (если нет бота).
8. В BotFather выполните /setmenubutton → выберите бота →
   текст «Открыть синтезатор» → HTTPS-ссылку из пункта 5.
9. Проверьте запуск внутри Telegram на телефоне. Сначала нажмите START AUDIO.

ВАЖНО:
- Не выкладывайте токен Telegram-бота на GitHub.
- Сайт публичный, использует только бесплатный GitHub Pages и HTTPS.
- Запись, скачивание файлов и работа в фоне зависят от версии Telegram/WebView.
- Пресеты хранятся в текущем браузере/Telegram; синхронизации нет.
- Для следующих изменений используйте отдельный ZIP с исходниками и Actions,
  а не смешивайте два способа публикации в одном репозитории.
