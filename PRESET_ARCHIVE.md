# Банк пресетов из ATMOSLAM Sample Forensics

## Источник

Получен пользовательский архив `reports.rar` (RAR5), содержащий 1 708 объектов, включая отчёты HTML, MD, спектрограммы и JSON. Читаемых `forensics.json` — 213; уникальных по SHA-256 исходного аудио — 212. Один анализ дублируется. Контрольных синтетических файлов — 5, они исключены. **Рабочих источников — 207**:

| Коллекция отчётов | Уникальных реальных анализов |
|---|---:|
| Phyllorum Horror | 59 |
| The Endless Knot — Percussions Collection | 56 |
| The Endless Knot — Ritual Environments | 39 |
| The Endless Knot — Bassline Collection I | 29 |
| The Endless Knot — Bassline Collection II | 24 |
| **Итого** | **207** |

`src/forensicsCatalog.js` — компактный справочник **фактических значений из отчётов** (в нём нет WAV/AIFF/FLAC, графиков или полного исходного RAR). У записи есть короткий хеш SHA-256, имя, библиотека, классификация, измерения, ритмические гипотезы и один пример 16-шагового рисунка по распознанным событиям.

`src/forensicsPresets.js` — **эвристика**, которая выбирает совместимый DSP-движок и вычисляет его параметры. Приоритеты: низкочастотная энергия и краткость огибающей для баса, спектральный центроид/шумность для перкуссии, тональность и эволюция для дронов, плотность атак для ритмического движка. Все физические параметры нормализуются с помощью реальной схемы `systems[os].params`.

## Категории

Категории могут содержать несколько DSP-движков. Кубик использует **путь всей видимой категории** в выпадающем списке. Он исключает исходный пресет, применяет новый пресет к текущей вкладке (не добавляя новую), сохраняет входное AUDIO/MIDI управление и пересоздаёт движок, если тип изменился. В категориях из одного пресета кубик выключен.

Оригинальные 26 Psycore / Slambient-патчей сериализованы в `src/preservedSynthPresets.js` **без изменений физических DSP-параметров и seed**. Старые не-psycore категории и 17 старых sample FX заменены. Служебный `Clean` оставлен для сброса эффекта на исходное аудио.

## Ограничения

- Это **приближённый resynthesis/sound-design**, а не достоверная реконструкция исходного семпла. Для оригинального звучания загружайте сам аудиофайл отдельно.
- Отчётный `BPM` часто неоднозначен (half/double-time); при адаптации к ритмическому движку используется художественный темп с ограничением по диапазону движка.
- Автоматическая классификация «snare», «bass» и музыкальных циклов из плотного микса не доказывает наличие соответствующего исходного инструмента или размера.
- JSON-паттерны сохранены как метаданные для будущего импорта в генератор, но в этой версии **не воспроизводятся пошагово**. Банк параметризует синтез и генеративные возбуждения; настоящую секвенцию на уровне событий нужно реализовать отдельно.
- Коммерческие аудиосемплы не копируются, пресеты не являются нативными файлами KICK 2 и не требуют KICK 2.

## Обновление каталога новыми отчётами

После распаковки будущего RAR с отчётами в папку (нужны именно `forensics.json`) выполните в корне проекта:

```sh
python tools/rebuild_catalog.py "C:\\Путь\\к\\извлечённым\\reports"
```

Скрипт не анализирует аудио повторно, а собирает метрики в `src/forensicsCatalog.js`. Для обновления банка используйте `npm run dev` или пересоберите проект. **Внимание:** изменения содержания и порядка каталога могут изменить индексы пресетов в ранее сохранённых JSON; для известных имён действует миграция по имени. Экспортируйте важные проекты перед обновлением каталога.
