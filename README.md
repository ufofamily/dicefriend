# diceFriend · Generative Network (новая версия)

В этой версии нет пользовательского ввода AUDIO/MIDI: музыкальная сеть создаётся синтезаторными вкладками, которые обмениваются возбуждениями. Новые настройки находятся в **Синтез → вкладка пресета → Связи**. На странице **Мастер** сохраняются запись WAV и короткий offline export. Базовый проект — 8 слоёв на 220 BPM. См. [GENERATIVE_NETWORK.md](GENERATIVE_NETWORK.md) и [GENERATIVE_VERIFICATION.md](GENERATIVE_VERIFICATION.md).

Модули для импорта старых JSON-проектов остаются в исходном коде исключительно ради совместимости; соответствующие вкладки загрузки AUDIO/MIDI не показываются.

Double-click `start.cmd` or `start-fixed.cmd`. # ATMOSLAM · Generative Studio — Forensics Preset Edition

Браузерный генеративный синтезатор (Vite + Web Audio + AudioWorklet) с банком **процедурных пресетов, построенных по отчётам ATMOSLAM Sample Forensics**. Музыка синтезируется существующими DSP-движками. В архиве **нет исходных звуковых файлов из коммерческих sample packs**.

## Быстрый запуск

На Windows просто запустите `start.cmd` — Node.js 20+ и npm будут настроены автоматически, если они отсутствуют. Альтернативный ручной запуск в терминале:

```sh
npm install
npm run dev
```

Откройте `http://127.0.0.1:5176/`. Установка npm-зависимостей требует доступа к пакетному реестру. Для сборки: `npm run build`.

## Что изменено

- **26 оригинальных Psycore / Slambient** пресетов сохранены с прежними значениями всех параметров и seed, включая Psy Roll, Neuro, Slam, Abyss, Ritual psycore, Slambient Textures/Kick/Bass и два тональных Slambient-патча.
- **207 пресетов по 207 уникальным анализам звуковых файлов** добавлены вместо старых не-psycore/slambient фабричных пресетов. Из 212 уникальных анализов пять синтетических контрольных файлов исключены из рабочего банка.
- **28 новых sample-FX пресетов** рассчитаны по признакам отчётов. Оставлен `Clean / исходный` как служебная настройка сброса.
- **Крупный кубик «ПРЕСЕТ» на деревянной панели над крутилками**: выбирает другую вариацию из категории, выбранной в списке, и **заменяет пресет активной вкладки** без создания новой. Название вкладки, параметры и подсказка на панели обновляются. MIDI-идентификатор вкладки, её маршрутизация, источник AUDIO/MIDI, синхронизация, фильтр и уровень сохраняются. Играющий DSP-движок переключается на новый экземпляр без остановки остальных вкладок.
- **Панель крутилок переработана:** 6 основных регуляторов назначаются по роли и DSP-движку пресета (например, kick, bass, metallic percussion, drone). Для проанализированных семплов приоритет может дополнительно зависеть от измеренных атаки, хвоста и спектра. Кнопка `СЛОЙ ↻` переключает **ЗВУК → ДЕТАЛИ → ГЕНЕРАЦИЯ**: 12 исходных DSP-параметров остаются доступны, а новая страница даёт 6 реальных параметров управления AUDIO/MIDI и фильтром. Старый маленький `DICE` по-прежнему рандомизирует **значения параметров**, не выбирая пресет.
- Сохранены две оригинальные слэмбиентные мастер-сцены и добавлены четыре новые сцены по отчётам (`Ritual Transmutation`, `Organic Pulses`, `Cavern Resonances`, `Horror Fragments`). Все сцены создают четыре вкладки, поддерживают AUDIO/MIDI управление.

## Как выбирать

1. На вкладке «Синтез» откройте **«Жанр / стиль / пресет»**.
2. Категории `Психоделический › ...` содержат сохранённые оригинальные звуки; категории `Анализ семплов › ...` — новые настройки по отчётам.
3. Выберите пресет и нажмите **«＋ Добавить»**, чтобы создать новую вкладку.
4. Либо нажмите **большой кубик «ПРЕСЕТ» на панели с крутилками**, чтобы случайно заменить звук **текущей вкладки** другим из выбранной категории. Кубик не добавляет вкладку и не повторяет уже загруженный пресет.
5. Кнопкой `СЛОЙ ↻` переключайтесь между тремя страницами ручек. На **ЗВУК** — шесть приоритетных для этого пресета параметров. На **ДЕТАЛИ** — оставшиеся шесть параметров движка. На **ГЕНЕРАЦИЯ** — плотность событий, вариативность, отклик, влияние AUDIO/MIDI, срез и смесь фильтра. Звёздочка у ручки означает, что её источник пока выключен. При первом изменении среза/смеси фильтр автоматически включается в режиме LP; параметры возбуждений действуют после выбора AUDIO/MIDI.
6. Включите звук кнопкой `Пуск`, если он не запущен. Генерация от аудио/MIDI в настройках возбуждений включается отдельно; пресет не принудительно переключает ваш источник управления.
7. Для многослойного звука выберите «Мастер-пресет», затем `Аудио` или `MIDI`, загрузите материал и запустите генерацию.

Сохранение/загрузка проекта JSON сохранены. Старые сохранённые проекты с пользовательскими настройками продолжают использовать параметры своих слоёв: идентификаторы пресетов при повторной загрузке корректируются по именам, если это возможно.

## Откуда взялись новые звуки

Из `reports.rar` извлечены машиночитаемые `forensics.json`. Для каждого аудиофайла были использованы длительность, низко/высокочастотная энергия, спектральный центроид, шумность, огибающая, особенности стерео, оценка ритмической плотности, BPM-гипотеза, циклы и частотная оценка тона, когда она надёжна. Эти величины преобразованы в физические параметры поддерживаемого DSP-движка, затем нормализованы в допустимый диапазон.

**Это не точное восстановление семплов и не загрузка их аудио в синтезатор.** По результатам анализа невозможно восстановить оригинальные инструменты, секвенсоры и FX-параметры. В `src/forensicsCatalog.js` сохранены исходные измерения и краткая информация о ритмических рисунках, в метаданных нового пресета — имя исследованного файла и оговорка об оценке BPM. Генеративный профиль на основе ритмической плотности выставляет характер/частоту возбуждений, но сам аналитический рисунок **не воспроизводится как последовательность отдельных нот**. Для этого нужен отдельный шаг интеграции MIDI-паттернов.

Подробнее: [PRESET_ARCHIVE.md](PRESET_ARCHIVE.md). Измеренные проверки: [VERIFICATION.md](VERIFICATION.md).
