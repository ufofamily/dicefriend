# diceFriend — audio stability / loudness correction

Обновление на базе **dicefriend-new-default-full.zip**. Стартовый проект `src/default-atmoslam-project.json` (8 вкладок / 220 BPM), пресеты, интерфейс, GitHub Pages workflow и MIDI-маршрутизация сохранены.

## Что исправлено

1. `src/audio/OutputConditioner.js` — лёгкое выравнивание уровней на выходе каждого DSP-движка: базовая компенсация семейства движков, ограниченная адаптация среднеквадратичного уровня, смягчение верхов (2 полюса) и soft-knee для опасных пиков. Выравнивание не является LUFS-нормализацией, не меняет параметры пресетов и не поднимает тишину бесконечно.
2. `src/dsp.js` — устойчивый topology-preserving фильтр для Rungler/Chaos вместо высокочастотно-неустойчивой схемы; расчёт коэффициентов каждые 32 сэмпла. Защитная обработка применяется и при offline-рендере.
3. `src/bass-dsp.js`, `src/hard-dsp.js`, `src/slambient-dsp.js` — ограничена максимальная мгновенная частота pitch-sweep кика (5,2 кГц или ниже в зависимости от sample rate), чтобы избежать ультразвуковых/алиасных срывов при высоких значениях ручек. У slambient bass первый шаг-импульс больше не может случайно пропасть.
4. `src/worklet.js` — плавный запуск (около 6 мс) и остановка (около 9 мс) вместо мгновенного обрыва буфера.
5. `src/engine.js` — короткий fade-out перед отключением звукового узла при смене пресета.

## Проверка

- Все **233** пресета проверены DSP-рендером при 16 кГц на тестовом интервале 1,2 секунды: нет NaN и превышения установленного пика 0,83 на выходе отдельного движка.
- В **163/233** пресетах RMS вырос на **≥1,9 дБ**, в основном у тихих резонаторных, атмосферных и тональных патчей. Часть уже громких пресетов не усиливалась.
- Количество пресетов с RMS ниже 0,01 в тестовом интервале: **1** (это короткий/разреженный генеративный сигнал, не означает неисправность).
- Проверены запуск/остановка AudioWorklet и спад до цифровой тишины.
- Пройдены `tests/dsp.mjs`, `tests/audio-stability.mjs`, `tests/worklet-fades.mjs`, `tests/forensics-presets.mjs`, `tests/category-dice.mjs`, `tests/preset-controls.mjs`, `tests/midi-timing.mjs` и другие базовые тесты.
- Встроенный стартовый сет (8 слоёв с сохранёнными уровнями) может суммироваться выше 0 dBFS **до** мастер-лимитера. Это ожидаемо для восьми одновременных голосов; при слишком сильной компрессии на мастере рекомендуется уменьшить уровни отдельных дорожек или master gain, а не ослаблять лимитер.

**Ограничения:** аудиопрослушивание на Windows, длительные тесты на мобильных браузерах и реальная опубликованная production-сборка не выполнялись. Некоторые шумовые/ритмические пресеты по замыслу используют высокочастотный материал, но его уровень и выбросы теперь контролируются. Защитная DSP-обработка меняет тембр относительно старой версии — при необходимости сохраните резервную копию.

## Установка в GitHub

Распаковать patch ZIP и загрузить его содержимое в корень репозитория, сохранив структуру `src` и `tests`, затем дождаться зелёной GitHub Actions сборки и обновить страницу (Ctrl+F5). JSON проекта и `package-lock.json` не заменяются.
