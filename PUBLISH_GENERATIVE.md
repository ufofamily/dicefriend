# Обновление ufofamily/dicefriend

1. Экспортируйте текущий проект JSON из интерфейса (резервная копия).
2. Распакуйте `dicefriend-generative-network-patch.zip`.
3. Загрузите его содержимое **в корень** репозитория `ufofamily/dicefriend` с сохранением папок `src`, `src/generative`, `tests` и заменой существующих файлов. Не загружайте ZIP как единственный файл.
4. Проверьте `Settings → Pages → Source: GitHub Actions`.
5. В `Actions` дождитесь успешной сборки и публикации.
6. Откройте `https://ufofamily.github.io/dicefriend/`, обновите через Ctrl+F5.
7. В разделе «Связи» для нескольких вкладок должен быть режим «Взаимодействие», а счётчик «принято» должен увеличиваться при запуске нескольких пресетов кнопкой «Все».

При наличии сохранённого старого проекта его источники AUDIO/MIDI/OFF автоматически переводятся в PEER, не удаляя параметры, уровень и seed. Отправка и приём включены по умолчанию (0.65), но можно выключить любую сторону.

Рабочий набор пресетов, стартовый JSON и конфигурация GitHub Actions не изменялись.
