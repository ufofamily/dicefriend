# ATMOSLAM — проверка пресетного обновления · 5 ноября 2026

## Успешно выполнено

- `node tests/forensics-presets.mjs`: 212 уникальных источников в каталоге, 207 актуальных DSP-профилей, 26 сохранённых psycore/slambient, 28 sample FX + `Clean`, все 12 параметров каждого профиля лежат в диапазоне своего движка, шесть сцен успешно создают четырёхслойные сессии.
- `node tests/category-dice.mjs`: выбор для всех 233 пресетов остаётся внутри текущего `optgroup`, не повторяет исходный индекс, обрабатывает граничные значения генератора случайного числа.
- `node tests/master-scenes.mjs`: шесть четырёхслойных сцен × AUDIO/MIDI, сигнальный выход, реакции на MIDI note-on, маршрутизация одной MIDI-дорожки на все четыре слоя.
- `node tests/genres.mjs`: 233 детерминированных пресета, положительная энергия в окне 3,2 с, нет дублирующихся аудиосигнатур и выходов за лимиты DSP; тест экстремальных BPM оставшегося движка.
- `node tests/dsp.mjs`: базовые проверки всех 24 движков, параметров, stereo, seed и тайминга.
- `node tests/bass-controls.mjs`: влияние всех 12 органов управления на 8 басовых/ритмических движков.
- `node tests/studio.mjs`, `node tests/midi-timing.mjs`, `node tests/sync.mjs`: PCM WAV, работу сэмпла, общее MIDI-время, loop и clock.
- `node tests/style-profiles.mjs`: разные исходные анализы дают разные музыкальные сигнатуры и уровни энергии.
- `node --check` для изменённых JS-модулей.

## Ограничения проверки

- `npm ci` не завершился за время теста: необходимые npm-пакеты не удалось получить. Поэтому `npm run build` здесь **не подтверждён**.
- Попытка открыть локальную страницу через Chromium/Playwright вернула `ERR_BLOCKED_BY_ADMINISTRATOR`. Проверка кликов и состояния UI в реальном браузере **не подтверждена**; логика выбора проверена отдельно как чистая JS-функция.
- Продолжительный регрессионный прогон был прерван ограничением времени во время `tests/ambient-controls.mjs`. Полный набор старых тестов не объявляется успешно пройденным.
- Никаких исходных звуковых файлов из пакетов The Endless Knot/Phyllorum в отчётах не было. Аудиальное сравнение с оригиналами **не проводилось**.

## Что проверить на вашем Windows-компьютере

```cmd
npm install
npm run build
npm run dev
```

В браузере: выбрать `Анализ семплов › Органическая перкуссия`, нажать `🎲 В категории`, проверить, что категория не изменилась, а имя/движок текущей вкладки изменились. Повторить во время воспроизведения и с несколькими вкладками. Проверить обе старые Slambient-сцены, четыре новые сцены, экспорт/импорт проекта JSON и старые сохранённые сессии.
